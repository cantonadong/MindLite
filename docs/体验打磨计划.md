- [x] 界面：统一节点/选中/完成/悬停样式、添加节点按钮、结构菜单状态、窄窗口工具栏、搜索与右键菜单。
- [x] 编辑：修复编辑失焦导致折叠按钮丢点击、工具栏后无法连续键入；完善中英文输入和节点间焦点转移。

- [x] 拖拽：指针捕获、逐帧更新、带连线的子树影子、原位保留、目标说明、边缘平移；限制循环及层级。

## 视觉方向

保留轻量白色画布和蓝色操作反馈。根节点使用用户主题色，普通节点淡底；选中态蓝色描边与清晰光晕；完成态可辨识的勾选与划线。左下结构/缩放与底部格式栏错开，菜单位置限制在窗口内。动画只用于布局变化和视口定位，并遵守暂停/减少动态效果设置。
