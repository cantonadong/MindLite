### 已定位并修正的问题

- MSVC 构建失败：PATH 命中了 Git 的 Unix link.exe，本机缺少 MSVC 链接工具。改用已安装的 Rust GNU 工具链自带 GCC 链接器。
- Rust GNU 缺少可独立工作的 dlltool/as：下载官方 llvm-mingw 20261006 便携包，只在项目 `target/toolchain-download` 中作为临时构建工具使用，不安装系统工具或修改全局 PATH。构建脚本在进程内加入其 bin 路径提供 dlltool；链接仍使用 Rust 自带 GCC，避免 LLVM UCRT 包缺少 libgcc_eh 的不匹配。
- PowerShell 5.1 默认按 ANSI 解码无 BOM 脚本，中文路径字符串导致说明文件复制失败。将脚本内路径改为 ASCII `README.md`，重新构建成功。
- 独立静态代码审阅修正：挂接子树的目标深度限制；命令行打开 .mm 按导入处理，禁止 JSON 覆盖原 .mm；原生另存及导出扩展名校验；保留 FreeMind 节点 ID，避免随机配色往返变化；激活中文 IME 直接输入；文档切换同步 Rust 当前保存路径。
