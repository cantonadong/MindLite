# MindLite 需求与开发方案（待确认）

依据：`need.md`、四张 `need.assets` 参考图、`dev规范.txt` 和用户全局工作规则。

## 目标与边界

开发 Windows 本地思维导图工具，以 Rust + WebView 为技术方向。完整覆盖需求中的文件操作、节点编辑、布局、拖拽、历史记录、文本格式和配色。第一阶段只交付独立可运行的 UI 预览；用户确认视觉及交互后才实现真实业务。预览中的文件操作使用模拟反馈，不读取或覆盖真实文档。

## 技术方案比较

- 推荐：Rust + Tauri + 系统 WebView2，前端使用 TypeScript、HTML/CSS 和 SVG。Rust 负责本地文件和原生对话框，前端负责节点交互、布局及画布。优先复用系统 WebView，避免附带完整浏览器；正式开发前核实依赖版本与本机运行环境。
- 备选：Rust + wry，直接管理 WebView 和消息桥。壳层较直接，但窗口、对话框和安全边界需要自行整合。
- 备选：Rust 原生 GUI。适合不依赖 WebView 的场景，但不符合当前建议，富文本及 SVG 式交互实现成本较高。

独立预览直接由浏览器打开，不依赖 Rust 编译、网络服务或完整打包。后续桌面应用复用预览的样式与画布组件。

## 页面与视觉

白色画布为主体，顶部放文档名和文件菜单，左下角放撤销、重做、结构与缩放控制，选中节点后显示底部固定格式工具栏。结构弹层参考原图，包含布局和分支线样式预览；分支线提供圆角折线和曲线。

节点采用浅灰背景和圆角，选中或悬停时出现蓝色描边；当前编辑或拖拽节点可使用蓝底白字突出。连线为细线，选中态蓝色参考截图。折叠按钮位于节点和子节点连线的交界处，收起态显示展开标记。拖拽时保留原位置轮廓，并用半透明子树与虚线框显示预计落点，禁止产生父子循环。

节点尺寸随文本调整，长文本换行；空白节点在非编辑态显示轻提示，编辑时不将提示写入数据。弹层不越出窗口，小窗口下工具栏允许收缩。

## 功能与交互

1. 新建时在视口中心显示一个空白根节点，可直接编辑。单击选中，双击或直接键入进入编辑；中文输入法组合输入期间不触发结构快捷键。
2. Tab 在选中节点下创建子节点，立即进入输入；Enter 创建同级节点并输入。根节点没有同级，拟定 Enter 创建子节点。Shift+Enter 在编辑节点时换行，Esc 结束编辑。
3. 拖动节点支持调整位置，拖到其他节点附近显示重新挂接预览；松手提交，Esc 取消。拟定自动布局下保存手动偏移，切换布局时清除偏移并重新排列；需用户确认。
4. 节点有子级时可折叠/展开，折叠不删除数据；拖拽预览包含可见子树。
5. 布局包含自动（默认）、右、左、下、左右。拟定自动按一级分支数量平衡左右；左右按顺序交替分配；左/右为单向展开，下为自上而下树形。
6. 缩放默认 100%，提供界面加减按钮、Ctrl +/-、Ctrl+滚轮、Ctrl+0；拟定范围 25%—300%。滚轮缩放以指针为中心，按钮缩放以视口中心为中心。空白区域拖动平移画布。
7. Ctrl+Z / Ctrl+Y 撤销与重做：节点增删、文本修改、移动、格式、完成、折叠、布局和配色均纳入历史；一次拖拽或一次文本编辑作为一次操作。视口缩放和平移不进入文档历史。
8. 底部工具栏支持粗体、斜体、下划线、完成。标记完成时递归完成全部后代，并以勾选和文字淡化显示。拟定取消完成也递归取消，需用户确认。
9. 配色模式：统一颜色；一级分支分别着色、后代继承；所有节点随机彩色。随机结果在保存后保持，不因重绘变化。
10. 提供十二色：珊瑚红 #E45B4A、活力橙 #F58B36、暖黄色 #F6C65B、浅绿色 #9BCF9B、森林绿 #398963、青绿色 #5DBCB2、湖蓝色 #67B9D7、柔和蓝 #6F90CF、薰衣草紫 #A99AD8、玫瑰粉 #D992B3、奶油白 #FFF2D4、深炭灰 #30333B。色号可复制；浅色需配深色文字以保证可读性。

## 文件与数据流程（UI 确认后实现）

- 原生文档拟用 `.mindlite` JSON，包含格式版本、根节点、子节点顺序、稳定 ID、文字、样式、完成/折叠状态、布局、颜色与手动位置。
- 打开/保存/另存通过原生对话框；打开、新建、关闭前有未保存修改时提供保存、放弃、取消。取消保存不继续破坏性动作，写入失败保留编辑内容。
- 导入 FreeMind `.mm` 时转换为内部节点树；导出 `.mm` 时保存文字、层级和可映射样式，对不能映射的应用专有属性给出说明。
- 图片导出拟支持 PNG 与 SVG，默认导出完整可见导图，包含折叠后的状态，不含工具栏；大画布超出导出限制时给出缩小比例选项。
- Rust 只暴露必要的文件命令，前端传递结构化数据；解析外部文档时限制大小和层级，不执行外部脚本或 XML 外部实体。
- 保存采用临时文件写入后替换的方式降低文件损坏风险；错误信息包含可操作的原因，不能静默丢失内容。

## 模块、依赖与交付顺序

1. 需求方案和日志：当前阶段，等待用户确认架构及拟定交互。
2. UI 预览：静态壳、mock 节点、布局切换、缩放、折叠、拖拽示意、格式及配色预览。提供 normal、loading、empty、error、长文本/深层级/多节点 edge case 切换；动画可触发、暂停和重播。交付独立 HTML 和启动 BAT，等待用户确认。
3. 编辑核心：节点树模型 → 布局计算 → 编辑/拖拽 → 撤销重做 → 格式/完成/配色。复用确认后的预览样式。交付同一路径 EXE，等待用户验证。
4. 文件模块：基于稳定模型接入原生保存、FreeMind 转换和图片导出。交付覆盖更新后的同一路径 EXE，等待用户验证。
5. 整合交付：完善异常和未保存保护，更新使用说明、任务日志与 Git 同步状态。

前端模块分为文档状态、布局引擎、SVG 连线、节点编辑、指针/键盘交互、工具栏、历史记录与预览场景。Rust 分为窗口壳、文件命令和格式转换，避免全部集中于单文件。

## 验证与开发约束

未经用户明确要求不运行测试。交付前进行必要构建，构建不等同于功能验收。用户测试版统一输出 `dist/MindLite.exe`，更新前终止已有 MindLite 进程并覆盖同一个文件。

只使用 main，不使用 worktree 或其他分支。当前目录尚无 Git 仓库和远端；待明确 GitHub 地址后按规范同步，不猜测仓库地址或擅自创建远端仓库。

如联网失败，遵守防火墙规则：新授权的可执行文件需终止全部旧进程，在等待 10 秒后以新进程重试。工具优先 Git Bash，不安装 winget。
