# MindLite 1.0

从 [GitHub Releases](https://github.com/cantonadong/MindLite/releases) 下载 `MindLite-1.0-win64.zip`，解压后双击 `MindLite.exe` 启动。请将同目录的 `WebView2Loader.dll` 一起保留；移动应用时复制整个文件夹。需要 Windows 10/11 x64 和 Microsoft Edge WebView2 Runtime。

## 记录想法

顶部标题可双击编辑，Enter 或点击外部提交，Esc 取消；重命名支持撤销并保存在 `.mm` 文件中。更改导图标题不会自动重命名磁盘上的已有文件，另存时默认使用新标题。

- 默认显示可编辑的中心节点。双击节点或选中后直接输入；F2 也可开始编辑。
- Tab 添加子节点并输入。节点正在编辑时，Enter 先提交文字并退出编辑；退出后再次按 Enter 才添加同级节点，根节点则添加子节点。长按 Enter 不会连续新增。
- Shift+Enter 换行，Esc 结束编辑。Delete 删除选中节点及其子树，根节点不能删除。
- 节点位置始终自动布局，不能自由拖到任意坐标。拖到其他节点整个节点框或加号区域，均改为其子节点；移出节点框上下边界后才可排在它之前/之后，向下布局改用左右边界。拖拽保留原有主分支方向，同级插入沿用目标分支方向。空白处松手取消，Esc 也可取消。中心节点不能拖动。
- 节点旁的 − / + 收起或展开子树。非编辑状态下，上下方向键切换同侧同级节点，左右按实际视觉方向切换父节点或子节点；向下布局时，上下切换层级，左右切换同级。Shift+上下将当前节点连同子树在同级中前移/后移，保持选中并支持撤销；不会跨到另一侧或改变层级。
- 叶节点悬停或选中后出现 +，单击即可添加子节点；右键节点可编辑、添加、折叠、复制、剪切和删除。
- 底部工具栏设置粗体、斜体、下划线和完成状态；完成与取消完成均递归应用于全部后代。
- 已完成节点以文本左侧的完成圆圈图标和划线显示，图标与文字水平居中对齐；向已完成分支添加、粘贴或挂接节点时继承完成状态。

## 搜索与剪贴板

- 非编辑状态下 Ctrl+A 只选取当前画布视口内的可见节点，不选择工具栏、标题或网页文字；折叠和视口外节点不计入全选。可对选中节点批量设置格式、完成状态或删除，Esc 恢复单选。
- 编辑节点或标题时 Ctrl+A 只选择当前输入内容。多选复制仅包含选中的可见节点；剪切/删除按子树处理，剪切会完整保留被移除子树的后代，避免内容丢失。

- Ctrl+F 搜索所有节点，包括折叠子树中的文字。Enter / Shift+Enter 切换结果并定位，Esc 关闭搜索。
- Ctrl+C 复制选中节点及全部后代；Ctrl+X 剪切子树；Ctrl+V 粘贴为选中节点的子节点。编辑文字时这些快捷键执行普通文本操作。
- 从外部复制的多行文字可直接粘贴为导图，Tab 或空格缩进转换为层级。复制到其他软件时输出缩进文本。
- 在同一应用实例中复制/剪切后，粘贴可保留格式、折叠和完成状态；新节点生成独立 ID。跨实例或来自其他软件的内容按缩进文本处理。

## 布局与颜色

左右展开时，同级节点/子树的垂直布局间隔统一为 20px（100% 缩放）；按外描边计算，包含多行文字和描边尺寸。子树较大时自动留出更多空间，避免后代重叠。向下布局保留横向同级间距。

左下角结构按钮切换自动、右、左、下、左右布局及圆角折线/曲线。节点始终按层级、同级顺序与子树大小自动排布；旧文件中的手动坐标偏移会被忽略。自动布局平衡左右分支，左右布局依次交替。

右上角配色按钮提供单一颜色、分支配色和随机彩色。分支配色按主分支分配，后代继承；随机彩色按节点分配。两者均将全部 24 色打乱后逐一使用，一轮用完才重新洗牌。同一文档重绘、折叠、保存重开及导出后保持一致。单一颜色模式仍统一使用主题色。主题色面板提供 24 种搭配颜色，按四列排列；点击色块选择主题基色，仅单一颜色模式的选中色块保留原色并显示加粗勾号，其他两种模式不显示勾号，不显示色号。

导图连线宽 2.6px、节点描边宽 2px；添加/展开按钮使用几何居中的 SVG 加号，导出图片同步使用相同线宽。

新建、打开、导入、恢复、示例和切换布局均默认 100%，不会因导图较大自动缩小。Ctrl +/- 或 Ctrl+滚轮可手动缩放（25%—300%）；Ctrl+0 恢复 100%。只有主动点击左下适应窗口按钮才按完整导图调整缩放。Home 或“结构”右侧的小房子按钮回到中心节点。拖动画布空白、按住鼠标中键或滚轮平移。Space 折叠/展开选中分支。

拖拽时仅将 A 子树原位置标为虚线，在目标处额外绘制 A 子树的插入预览及连线；B 保持原位，下方受影响的分支临时让位，按钮和连线同步调整，其他节点不复制、不淡化。拖拽期间画布不自动平移。没有有效目标时不显示插入预览，空白松手或 Esc 取消并恢复临时位置。松手确认后才改变层级/顺序并执行自动布局。

插入预览使用挂接生效后的节点尺寸、换行和子树内部相对位置，就近排在 B 已有子树之后，按完整子树范围留出至少 20px。不再把插入预览推过下方的其他分支，而是仅让受影响分支逐级让位；临时让位不会写入文档，松手后仍执行正式自动布局。

拖动 A 到 B 时，以 B 的屏幕位置为锚点计算 A 的插入预览，松手提交后以视口补偿保持 B 的屏幕中心。这不会保存手动节点坐标，也不会改变缩放比例。

## 文件

- 文件 → 打开、保存、另存，默认格式为 FreeMind `.mm`（UTF-8 XML）。已有文件按 Ctrl+S 直接覆盖保存，旧 `.mindlite` 文件名也保留；新建首次保存及主动另存时默认选择 `.mm`。
- 导入/导出 FreeMind `.mm`。导出保留文字、层级、左右方向、折叠、粗体与斜体；应用专属样式使用 XML 扩展属性，其他软件可能忽略这些属性。导入的左右分支方向保持原分配，主动切换结构后重新布局。
- 导出 PNG 或 SVG 包含完整可见导图，不含工具栏；折叠内容保持隐藏。超大 PNG 可选择缩小导出或使用 SVG。
- 新建、打开、关闭前如有修改，会询问保存；取消保存会留在当前文档。
- 最近未保存内容和原文件路径会原子写入 `%LOCALAPPDATA%/MindLite/recovery.mindlite`，异常退出后下次启动可恢复。恢复已打开的文件后，保存直接覆盖原文件，包括旧 `.mindlite` 文件名；内容按默认 FreeMind XML 保存，程序再次打开时自动识别。新建未保存、导入副本及旧版无路径恢复记录仍需首次选择保存位置。
- 可将 `.mindlite` 或 `.mm` 文件路径作为命令行参数打开。如果外部 `.mm` 包含当前版本不能完整保留的备注、链接等属性，会提示以副本打开，另存时保留原文件。通过“导入”打开的文件也按副本处理。

Ctrl+N 新建，Ctrl+O 打开，Ctrl+S 保存，Ctrl+Shift+S 另存。Ctrl+Z / Ctrl+Y 撤销/重做；一次编辑和一次拖动各作为一个操作，最多 100 步，大文档同时受历史内存预算限制。Ctrl+B / I / U 切换格式。

文档限制：20 MB、10,000 个节点、100 层、单节点 20,000 字符。导入超长文本会明确报错，避免静默截断。导入包含 DTD/外部实体声明的 XML 会被拒绝。保存采用同目录临时文件写完后替换，避免中途中断破坏原文件。

## 独立预览与开发

项目根目录 `预览MindLite.bat` 或 `ui/preview.html` 打开无需安装的 mock 预览，覆盖正常、空白、加载、错误和边界场景。可触发、暂停和重播折叠演示，预览模式不写入文件。

根目录执行 `build.bat`，会进行 JavaScript 语法检查、Rust Release 构建，再终止旧 MindLite 进程并覆盖 `dist/MindLite.exe`。不执行任何测试，也不自动启动应用。

WebView 数据保存在 `%LOCALAPPDATA%/MindLite/WebView`，不写入 EXE 所在目录。

当前为体验完善的用户验收版；已构建和静态审阅，并在启动故障修复后完成授权的启动诊断，确认窗口、WebView2 和前端初始化。未运行自动化或业务功能测试。

如果无法启动，可运行同目录 `Start-MindLite.bat` 查看退出码；应用启动日志位于 `%LOCALAPPDATA%/MindLite/mindlite-startup.log`。构建脚本已固定使用 LLD，修复旧 GNU 链接器导致的启动前访问冲突。
